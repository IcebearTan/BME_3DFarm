# BME 3DFarm 打印机跨网接入 — 实施与运维

> 实施日期：2026-07-14
> 相关：`docs/校园网部署与跨网接入指南.md`（早期方案探讨，含 Tailscale；本文记录**实际落地**的 loopback 方案）

## 1. 现状与最终方案

服务器（跑 BME_3DFarm + Bambuddy）与 Bambu 打印机分处两个路由器的 LAN，均接入校园网：

- **服务器**：路由器A LAN `192.168.1.181/24`，网关 `192.168.1.1`，路由器A WAN = `172.25.56.83`
- **打印机**：路由器B LAN `192.168.1.x`，路由器B WAN = `172.25.56.19`（**静态**，向学校网络信息中心申请的入网许可）
- 校园网**无 AP 隔离**（实测服务器 ping `172.25.56.19` 通，0.6ms）——不需要 Tailscale / 内网穿透

**最终方案**：路由器B 端口转发 + 服务器 loopback 转发 + Bambuddy 填 loopback IP。

```
Bambuddy(服务器) → 127.0.0.X:8883 ─(socat)─→ 172.25.56.19:800X ─(路由器B映射)─→ 打印机:8883
```

## 2. 为什么需要 loopback 转发（关键约束）

Bambuddy 连打印机走 MQTT-over-TLS，源码（容器内 `/app/backend/app/services/bambu_mqtt.py`）确认：

- `MQTT_PORT = 8883` 类常量，`connect_async(self.ip_address, self.MQTT_PORT)` —— **端口恒为 8883，不支持 ip:port 自定义端口**
- `check_hostname=False, verify_mode=CERT_NONE` —— **不验证 TLS 证书/hostname**
- `username_pw_set("bblp", access_code)` —— username 固定 **`bblp`**（不是 `bambu`）

多台打印机共用一个校园网 IP（172.25.56.19），必须用不同 WAN 端口区分（8000/8001/8002），但 Bambuddy 只连 8883。利用 `127.0.0.0/8` loopback 段 + Bambuddy 不验证 hostname：每台打印机分配一个 loopback IP，都监听 8883，socat 转发到各自映射端口。**不需要为每台机申请独立校园网 IP。**

|---|---|---|---|---|---|
| A | `01P00C5A2201216` | 172.25.56.19:8000 → :8883 | 127.0.0.3:8883 | Bambu-A | 1 |
| C | `01P00C5A1600996` | 172.25.56.19:8002 → :8883 | 127.0.0.2:8883 | Bambu-C | 2 |

- **access_code**：每台打印机"开发者模式 / 局域网访问"页面显示的 hex 串，会**手动刷新后旧码失效**，刷新后须 PATCH 更新 Bambuddy 的 printer 记录。本文不写死具体值，以打印机当前显示为准。
- 序列号可从 TLS 证书 CN 读取（`openssl s_client`），无需手动查。

## 4. systemd 持久化

每台打印机一个 service：`/etc/systemd/system/bambuddy-lb-<port>.service`

```ini
[Unit]
Description=Bambuddy loopback forward: 127.0.0.X:8883 -> 172.25.56.19:800X (printer ...)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/usr/bin/socat TCP-LISTEN:8883,bind=127.0.0.X,fork,reuseaddr TCP:172.25.56.19:800X
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

当前已部署：`bambuddy-lb-8000.service`（127.0.0.3）、`bambuddy-lb-8002.service`（127.0.0.2），均 `enable --now`。开机自启 + 挂了自动重启。

管理：
```bash
systemctl status bambuddy-lb-8000
systemctl restart bambuddy-lb-8000
```

## 5. 加新打印机流程

1. **路由器B**：WAN 端口转发 `172.25.56.19:<新端口> → 打印机局域网IP:8883`；并给打印机做 DHCP MAC-IP 绑定（防 IP 漂移）。
2. **打印机**：刷新 access code（开发者模式页面），记下 hex 码。
3. **服务器**：选空闲 loopback IP（如 127.0.0.4），写 `bambuddy-lb-<port>.service`（socat `127.0.0.4:8883 → 172.25.56.19:<端口>`），`systemctl enable --now`。
4. **验证链路**：`nc -vz 172.25.56.19 <端口>` 通；`openssl s_client -connect 172.25.56.19:<端口>` 看证书 CN = 序列号。
5. **Bambuddy test**：
   ```bash
   curl -X POST "http://127.0.0.1:8000/api/v1/printers/test?ip_address=127.0.0.4&serial_number=<SN>&access_code=<CODE>"
   # 期望 {"success":true}
   ```
6. **Bambuddy create**：
   ```bash
   curl -X POST "http://127.0.0.1:8000/api/v1/printers/" -H "Content-Type: application/json" \
     -d '{"name":"Bambu-X","serial_number":"<SN>","ip_address":"127.0.0.4","access_code":"<CODE>"}'
   ```
7. **connect + 验证**：
   ```bash
   curl -X POST "http://127.0.0.1:8000/api/v1/printers/<id>/connect"
   curl "http://127.0.0.1:8000/api/v1/printers/<id>/status"   # connected=true
   ```

Bambuddy API `auth_enabled=false`，无需登录即可调 REST。test 用 query 参数，create 用 JSON body。

## 6. 排坑记录（重要，避免重蹈覆辙）

| 坑 | 现象 | 真相/解法 |
|---|---|---|
| MQTT username | paho 用 `bambu` 全 `rc=5 not authorised`，误判 access code 无效 | 正确 username 是 **`bblp`**（Bambuddy 源码 `username_pw_set("bblp", ...)` 确认） |
| mosquitto TLSv1.3 | mosquitto_sub 连上只 `sending CONNECT`、收不到 CONNACK | Bambu broker 在 TLSv1.3 下握手成功但 CONNACK 解不开；**强制 TLSv1.2**（paho `ssl.SSLContext(PROTOCOL_TLSv1_2)`） |
| Bambuddy 端口 | Bambuddy test `ip:8002` 返回 success:false | Bambuddy 硬连 8883 不认 8002；用 loopback 转发绕开 |
| access code 过期 | 之前能连的码突然 rc=5 | 手动刷新后旧码失效；重新刷新取新码 |
| 路由器重置 | 打印机局域网 IP 漂移，端口转发指错机 | 重置前备份 WAN 配置；给打印机 MAC-IP 绑定 |

## 7. 调试命令速查

```bash
# 映射端口 TCP 透传
nc -vz 172.25.56.19 8002

# 看证书序列号（确认端口指向哪台机）
openssl s_client -connect 172.25.56.19:8002 </dev/null 2>/dev/null | grep subject=

# Bambuddy printer 列表 / 状态
curl -s http://127.0.0.1:8000/api/v1/printers/ | python3 -m json.tool
curl -s http://127.0.0.1:8000/api/v1/printers/1/status | python3 -m json.tool

# Bambuddy 容器日志
docker logs 3dfarm-bambuddy --tail 50

# loopback 转发是否在听
ss -lnt | grep 127.0.0
```
